# 🐱 Кошачья охота (Cat Hunt)

Android-игра для кошек: по экрану бегают мышки, таракашки, верёвочки, порхает бабочка и носится лазерная точка,
звучат привлекающие кошек звуки, а если кошка поймала добычу — вспышка и салют из искр.

## Скачать

Готовые APK — в разделе [Releases](../../releases).

## Сборка

```sh
./gradlew assembleDebug
# → app/build/outputs/apk/debug/app-debug.apk
```

Требуется JDK 17 и Android SDK (platform 35, build-tools 35.0.0).

## Выход из игры

Двойное нажатие «Назад» — чтобы кошка случайно не закрыла игру лапой.
